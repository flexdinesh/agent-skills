# Context Format

```md
# {Context Name}

{One or two sentence description of what this context is and why it exists.}

## Language

**Order**:
{A one or two sentence description of the term}
_Avoid_: Purchase, transaction
```

Be opinionated when multiple words mean the same thing, keep definitions to one or two sentences, include only terms specific to the project, and group terms under subheadings when natural clusters emerge.
